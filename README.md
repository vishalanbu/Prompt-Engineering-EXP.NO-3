2. What is Google? 
Google is a technology company and search engine that helps people find information 
on the internet. It allows users to search for websites, images, videos, news, maps, and 
many other types of information. 
Google is one of the most widely used search engines in the world. 
Simple Workflow of Google (How Google Works) 
1. Crawling 
Google uses special programs called web crawlers (bots) to scan and visit 
different websites on the internet. 
2. Indexing 
The information collected from websites is stored and organized in Google's 
database, called the index. 
3. Processing the Query 
When a user types a search query in Google, the system analyzes the keywords in 
the query. 
4. Ranking the Results 
Google compares the query with its indexed data and ranks the most relevant 
websites using its algorithms. 
5. Displaying Results 
Finally, Google shows the best matching results on the search results page for 
the user.
